## Méthodologie

- Collecte automatisée via Playwright (`scraper.py`) — sources tentées : Bien'ici, Leboncoin, PAP, SeLoger.
- Bien'ici : interception des réponses API JSON (endpoint `realEstateAds`) — source principale fiable.
- Leboncoin / SeLoger / Logic-Immo : bloqués par Datadome (403) — non utilisables sans proxy.
- Filtres appliqués : prix ≤ 600 €, centre-ville, pas de colocation.
- Dédoublonnage par URL et par triplet (surface, loyer, pièces).
- Rapport auto-généré : regénère simplement via `python generate_report.py`.
